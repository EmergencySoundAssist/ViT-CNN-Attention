## 설계 결정 로그 (왜 이렇게 했나)

| 결정 | 이유 |
|------|------|
| 검출=모델 / 속도=물리 DSP | 검출만 진짜 라벨 존재, 속도는 합성뿐 → sim-to-real 회피 |
| 균일 n배속 *라벨*의 속도 학습 **폐기** | 라벨 모순, 단일 관측 식별 불가(±50 km/h 바닥) |
| 대신 `synth_passby` 학습 | 통과 비율은 source-무관 → 라벨 일관, 학습 가능 |
| 추정은 **연속 km/h**, 알림은 tier 비닝 | 도플러가 연속·준선형(Δf/f≈v/c) → 회귀가 보간 일반화에 유리, 절대정밀도 부담은 출력 비닝이 제거 |
| 검출 윈도우 5초 | 소방차 wail 1주기(~4.7s) 포함 |
| 차종 ID 비핵심 | 피치×사이클로 51%, Airacle 3-클래스에 불필요 |
| Jetson Orin (RPi5 아님) | GPU+TensorRT → ViT 실용화, 모델 선택 자유 |
