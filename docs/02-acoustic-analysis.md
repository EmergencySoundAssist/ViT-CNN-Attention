# 02 · 사이렌 음향 특성 실측

> 모든 수치는 로컬 AI Hub 사이렌 클립(차종별 표본 ~200개)에서 직접 측정.
> 스크립트: [`analyze_siren_freq.py`](../analyze_siren_freq.py), [`analyze_siren_cycle.py`](../analyze_siren_cycle.py)

## 1. 정지 기준 주파수 (f_src)

한국 사이렌은 법적 규격이 없지만 **물리적 주파수는 좁게 군집**한다.

| 지표 | 값 |
|------|-----|
| 기본주파수 f0 (HPS) | **~320 Hz** (IQR 270–385) |
| 지배 톤 (가장 센 성분) | **~960 Hz** = f0의 3배음 |
| 집중 대역 | 700–1200 Hz 에 **87%** |
| 정지(제작) 녹음만 | ~996 Hz (더 타이트) |

**차종별 지배 톤**: 경찰 968 / 구급 937 / 소방 981 Hz — 거의 겹침 (차종 규격 없음과 일치).

**자연 녹음의 도플러 흔적**: 인위적(정지) 녹음은 996 Hz로 타이트, 자연 녹음은 941 Hz로 넓고 아래로 치우침 → 실환경에 이탈(낮은 음) 도플러가 섞여 있다는 증거.

### 함의
정지 기준 주파수를 **데이터로 확정**할 수 있다. 단, 개체 간 산포(±15%)가 도심 도플러(±4%)보다 커서, **모집단 평균만으로는 단일 관측 절대속도를 못 푼다.** ([docs/03](03-doppler-speed.md))

## 2. 사이클 주기 (wail/yelp 반복)

주파수 변조의 주기를 자기상관으로 측정.

| 차종 | 피치 | 사이클 주기 | 특징 |
|------|------|------------|------|
| 경찰차 | ~1077 Hz | **0.34 s** (98% < 0.6 s, 매우 일정) | 표준화된 빠른 yelp |
| 구급차 | ~969 Hz | 90% 0.34 s, 6% 느림(~1.75 s) | 평범 |
| 소방차 | ~969 Hz | **이봉**: 62% ~0.2 s / 37% ~4.7 s | 빠른 yelp + 느린 wail 혼재 |

## 3. "피치 × 사이클"로 차종 구분되나?

가설: *"하이톤 + 느린 사이클 → 구급차"* 같은 판별.

**결과 (피치×사이클 2D, 최근접중심 LOO):** 정확도 **51.5%** (랜덤 33%).

- 메커니즘은 유효(피치 단독보다 정보 늘어남).
- 그러나 구체 매핑은 데이터와 다름: **느린 사이클은 구급차가 아니라 소방차**(~4.7 s 장주기). 경찰차가 "하이톤 + 빠른 일정 사이클".
- 경찰 ↔ 구급은 피치·사이클 둘 다 겹쳐 2-feature로 분리 불가.

### 함의
- **차종 ID는 Airacle 3-클래스(siren/horn/noise)에 불필요** → 비핵심.
- **사이클의 진짜 가치는 검출**: 사이렌 = "0.2~5초 주기로 피치가 반복 변조"되는 것. 경적·주행음·비행기엔 이 변조가 없음. → CNN+Attention의 **Temporal Attention**, ViT의 self-attention이 잡으라고 만든 패턴.
- 검출 입력 윈도우는 **5초 권장** (소방차 wail 1주기 ~4.7s를 담아야 함; 3초는 짧음).

## 4. 측정 방법 요약

- STFT: `n_fft=2048`, `hop=256~512`, band 300–2500 Hz
- 지배 톤: 프레임별 대역 내 최대 peak (prominence 필터)
- 기본주파수: Harmonic Product Spectrum
- 사이클: 주파수 트랙 / 진폭 envelope 의 자기상관 1차 피크 (sub-frame 보간)
