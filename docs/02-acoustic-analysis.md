# 02 · 사이렌 음향 특성 실측

> 모든 수치는 로컬 AI Hub 사이렌 클립(차종별 표본 ~200개)에서 직접 측정.
> 스크립트: [`analyze_siren_freq.py`](../analyze_siren_freq.py), [`analyze_siren_cycle.py`](../analyze_siren_cycle.py)

## 1. 정지 기준 주파수 (f_src)

한국 사이렌은 법적 규격이 없지만 **물리적 주파수는 좁게 군집**한다.

| 지표 | 값 |
|------|-----|
| 기본주파수 f0 (HPS) | **~334 Hz** (IQR 285–355) |
| 지배 톤 (가장 센 성분) | **~964 Hz** ≈ f0의 3배음 |
| 집중 대역 | 700–1200 Hz 에 **85%** |
| 정지(제작) 녹음만 | ~1012 Hz (더 타이트) |

**차종별 지배 톤**: 경찰 978 / 구급 934 / 소방 964 Hz — 거의 겹침 (차종 규격 없음과 일치).

**자연 녹음의 도플러 흔적**: 인위적(정지) 녹음은 1012 Hz로 타이트, 자연 녹음은 942 Hz로 넓고 아래로 치우침 → 실환경에 이탈(낮은 음) 도플러가 섞여 있다는 증거.

### 함의
정지 기준 주파수를 **데이터로 확정**할 수 있다. 단, 개체 간 산포(±15%)가 도심 도플러(±4%)보다 커서, **모집단 평균만으로는 단일 관측 절대속도를 못 푼다.** ([docs/03](03-doppler-speed.md))

## 2. 사이클 주기 (wail/yelp 반복)

주파수 변조의 주기를 자기상관으로 측정.

| 차종 | 피치 | 사이클 주기 | 특징 |
|------|------|------------|------|
| 경찰차 | ~1098 Hz | **0.35 s** (97% < 0.6 s, 매우 일정) | 표준화된 빠른 yelp |
| 구급차 | ~947 Hz | 90% ~0.33 s, 10% 중간(0.6–2 s) | 평범 |
| 소방차 | ~991 Hz | **이봉**: 61% ~0.27 s / 38% ~4.7 s | 빠른 yelp + 느린 wail 혼재 |

## 3. "피치 × 사이클"로 차종 구분되나?

가설: *"하이톤 + 느린 사이클 → 구급차"* 같은 판별.

**결과 (피치×사이클 2D, 최근접중심 LOO):** 정확도 **53.0%** (랜덤 33%).

- 메커니즘은 유효(피치 단독보다 정보 늘어남).
- 그러나 구체 매핑은 데이터와 다름: **느린 사이클은 구급차가 아니라 소방차**(~4.7 s 장주기). 경찰차가 "하이톤 + 빠른 일정 사이클".
- 경찰 ↔ 구급은 피치·사이클 둘 다 겹쳐 **2-feature로는** 분리 불가.

### ⚠ DL은 다르다 — 손수특징 53% → CNN 87% (`subtype_clf.py`)

전체 멜 스펙트로그램에 CNN+Attn을 학습하면 **test 정확도 86.9% · macro-F1 0.869** (siren 청크만, 차종 균형 샘플러). 음색·배음 구조가 2D 피치×사이클이 놓친 걸 잡는다. 혼동행렬:

| 정답\예측 | 구급 | 경찰 | 소방 | recall |
|---|---|---|---|---|
| 구급차 | 1178 | 119 | 41 | 0.88 |
| 경찰차 | 123 | 601 | 12 | 0.82 |
| 소방차 | 60 | 8 | 626 | **0.90** |

- **소방차는 잘 분리**(이봉 사이클 구조), **경찰↔구급이 주 혼동**(242건) — 한국 사이렌 규격 부재와 일치.
- ⚠ 차종 분류엔 **피치/타임스트레치 증강 금지**(차종이 피치/사이클에 일부 있어 라벨 흐림 — 속도 head와 동형). 잡음 증강만 안전.

### 함의
- **차종 ID는 검출(3-클래스)엔 불필요**하지만, **HUD 차등 출력엔 viable**(87%) → 통합모델 head 후보. 단 안전 행동은 차종 무관이라 **UX 풍부함**이며, 경찰/구급 혼동 때문에 HUD는 **신뢰도 게이팅**(애매하면 "긴급차량") 권장.
- **사이클의 진짜 가치는 검출**: 사이렌 = "0.2~5초 주기로 피치가 반복 변조"되는 것. 경적·주행음·비행기엔 이 변조가 없음. → CNN+Attention의 **Temporal Attention**, ViT의 self-attention이 잡으라고 만든 패턴.
- 검출 입력 윈도우는 **5초 권장** (소방차 wail 1주기 ~4.7s를 담아야 함; 3초는 짧음).

## 4. 측정 방법 요약

- f_src(§1): STFT `n_fft=8192, hop=4096` (주파수 해상도 우선), band 300–2500 Hz —
  지배 톤 = 프레임별 최대 peak(prominence 필터)의 중앙값, 기본주파수 = HPS
- 사이클(§2): STFT `n_fft=2048, hop=512` — 주파수 트랙 / 진폭 envelope 자기상관 1차 피크
  (sub-frame 포물선 보간은 `doppler_speed.py`에 구현; 분석 스크립트는 정수 lag)
- 분석 구간: **클립 wav 앞 8 s(f_src) / 12 s(사이클)** — wav 전체가 사이렌 구간 ([docs/01](01-dataset.md) 함정 #3)
- 수치는 좌표계 결함 수정 후 전체 클립 재측정값 (2026-06-11)
